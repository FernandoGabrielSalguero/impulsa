Local Coding Assistant

Codex Local

Podés usar esta misma interfaz para abrir distintos proyectos locales y después enfocarte en una carpeta interna puntual si hace falta.

Cómo usarlo

  • Elegí primero el proyecto o workspace local que querés abrir.
  • Después definí el alcance: todo el proyecto (`.`) o una subcarpeta concreta.
  • Cargá el árbol y marcá los archivos que querés usar como contexto.
  • Pedí cambios concretos, refactors, fixes o revisiones sobre ese contexto.

Workspace y árbol

No hace falta instalarlo por cada proyecto. Podés cambiar de workspace y reutilizar la misma interfaz.
