Codex Local

Trabaja siempre sobre el proyecto instalado en este servidor. Usá el árbol para leer contexto real, previsualizar código y adjuntar archivos al chat.

Cómo usarlo

  • Cargá el árbol del proyecto y explorá la estructura real del servidor.
  • Hacé click en un archivo para ver su código sin salir del panel.
  • Marcá los archivos relevantes para usarlos como contexto del pedido.
  • Elegí las tecnologías con las que querés que trabajemos antes de enviar.
